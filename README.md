## Overview

Login Security adds login rules for admins. Sessions can end after a time without activity or after a set number of hours, remember me can be turned off, and a second factor can be required at every login or on a new device.

It works with whatever second factor plugins are installed, like TOTP or WebAuthn. People who have none yet are asked to set one up right after they sign in.

Read the [docs](https://docs.termix.site/plugins/login-security) to set it up and use it.

<br />

## Features

- Sign out after a set time without activity, in the browser and on the server
- Limit how long a session can last
- Turn off remember me and remembered devices
- Require a second factor at every login or on a new device
- Works with any installed second factor, like an authenticator app or a security key
- People without a second factor are asked to set one up before they can use Termix
